# Stop verifier review, 2026-09-12

The updated verifier uses contextual model judgment for scope, evidence, and deferrals, with smaller deterministic code for parsing, lifecycle integrity, and definite artifact contradictions. Every corrective action is generated by the model from the actual task and evidence.

| Finding | Change |
|---|---|
| Scripted interviews and repair fallbacks could reject complete work or prescribe irrelevant checks. | Removed keyword task routing, the second action-synthesis path, fixed interview orders, and automatic verification-directory requirements. |
| Timestamp age could invalidate still-valid evidence. | The model judges causal freshness from relevant changes and state. Absolute media existence remains a deterministic check. |
| Proof handling duplicated execution and could lose context. | One execution path handles verdict and one reconsideration, preserving context within one deadline. |
| No-action deferrals could bypass verification. | Every active request is audited, with child, empty-request, and active-work bypasses retained. |
| Invalid verdicts and infrastructure failures could resemble completion. | Strict parsing and distinct blocked, unavailable, and unverified states. Fork failure and unexpected verifier exceptions clear stale completion badges. |
| Tool evidence could be misattributed or lose the failure in long output. | Match call IDs or unambiguous positions, retain process status and bounded tails, and mark ambiguity unknown. |
| Worker notifications and injected steering could replace the user's goal. | Preserve source identity, applicable constraints, and literal text resembling compaction markers. |
| Duplicate hooks could loop or miss changed evidence with the same line count. | Hash transcript content, bound unchanged rejection replays, and audit changed evidence. |
| Tests could certify wording instead of judgment. | Retain structural regressions and independently evaluate actual model decisions and action meanings. The scorer shares runtime JSON extraction. |

The final local suite passed 277 tests and 361 subtests. Ruff passed. The focused stop-verifier topic covers schema, provenance, artifact, lifecycle, and semantic-runtime wiring. Mocked tests prove mechanics, not model reasoning.

On the independent 15-case matrix, the saved baseline matched 13/15 decisions while the candidate matched 15/15 on the first paired run with Gemini 3.8 Flash (Medium) and 20 seconds per call. The baseline falsely demanded an interview for a fully specified plan and extra runtime checks beyond a local-mock task's scope. The second candidate pass timed out after three matches. Two complete candidate passes with a 40-second evaluation budget matched 30/30 verdicts and completion states. The earlier failure is preserved; the runtime default is unchanged.

An independent Medium reviewer accepted all 18 completed steering outputs from the 20-second run. Codex inspected the later 30 outputs against the original requests, including preserving read-only scope for a misleading deletion log. The 28-case Low regression outputs all match with runtime parsing; the original scorer's rejection of fenced JSON is retained alongside the corrected score.

Delivery was checked beyond verdict matching. The native hook rejected a broken CSV parser. A separate Medium worker received that exact steering and repaired the fixture while preserving protected checks and inputs. Codex ran the original harness plus doubled-quote, multiline, CRLF/Unicode, and empty-file cases. A fresh native hook accepted the same repaired source hash. Stop, PostInvocation, persisted state, and unchanged parent-history checks passed.

The independent source review identified defensive exception handling and the absolute-only media check. Exception handling and fork-failure state were fixed with regressions. Relative media citations remain an explicit limitation requiring contextual inspection, rather than expanded path heuristics.
